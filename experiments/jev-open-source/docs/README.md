# Jev 系列实验：文档

本目录包含部署指南、复现教程、实验报告和原始日志。

- **[自己复现.md](自己复现.md)**：RTX 4090 文本训练环境的 uv 配置、CUDA 兼容问题与 GPU 检查记录。
- **[部署指南.md](部署指南.md)**：面向只想在本地部署单个模型接入业务的人。包含选型表、机器要求、环境配置、单模型部署步骤、验证方式与生产注意事项。
- **[复现教程.md](复现教程.md)**：面向想重跑整套评测、对齐报告数字的人。包含四个模型的权重对照、运行顺序、日志读法与脚本映射。
- **[实验报告.md](实验报告.md)**：延迟与准确率两张表、三个结构性发现、测量口径、上游数据取舍说明以及证据边界。
- **[执行日志/](执行日志/)**：历史实测包含 19 份终端日志 + 1 份结构化基准 JSON，编号 01 至 17 对应各阶段脚本。

- **[复现修正说明.md](复现修正说明.md)**：实现修正、历史数字的适用边界和无需模型权重的回归检查命令。

各模型的部署细节、特有步骤与坑，在各自子目录的 README 里。
